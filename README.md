# Python Day 135 - Count Words in a Sentence

## Description
This Python program counts the total number of words in a sentence entered by the user.

## Example
**Input:**
`I am learning Python`

**Output:**
`Total words: 4`

## Concepts Used
- User Input
- Strings
- split()
- len()

## How to Run
1. Install Python.
2. Run `count_words.py`.
3. Enter a sentence to count its words.
